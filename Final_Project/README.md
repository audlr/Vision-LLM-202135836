# 최종 프로젝트 : 체크아웃 소지품 체커

숙소에서 나갈 때 두고 가는 물건을 카메라가 확인하고 음성으로 알려주는 Jetson Nano 온디바이스 Vision-LLM 시스템

## 파일 구조

* `run.py`: 실행 진입점. `vision.py`를 별도 프로세스로 띄우고 이 터미널에서 `assistant`를 실행, q로 함께 종료
* `config.py`: 모델 경로, 카메라 파이프라인, 탐지 클래스·신뢰도 기준, 추적 기준값(4장 중 3장, 4.5초, 25% 이동) 등 설정
* `vision.py`: 프로세스 1. 카메라 → 2초마다 사진 처리 → 체크인·체크아웃 판단, 화면 표시, `state.json` / `event.json` 저장
* `detector.py`: YOLO11n INT8 엔진 탐지(클래스별 신뢰도 기준) + 초록 마커 LAB 색 분할 탐지
* `tracker.py`: 이전 사진과 IoU 매칭, 있음 / 이동 / 확인 안 됨 판정, 같은 종류 번호 붙이기, 주변 물건 기준 위치 설명
* `assistant.py`: 프로세스 2. Enter로 질문 받기 → 의도에 맞는 답 생성(규칙) → 음성 출력, `control.json`으로 vision에 명령 전달
* `intent.py`: Gemma 4 E2B로 질문 → 의도 JSON, 실패 시 키워드 규칙으로 대체, "휴대폰 2" 같은 번호 인식
* `speech.py`: Whisper STT, Piper TTS (06 수업 코드)
* `common.py`: JSON 원자적 읽기·쓰기, IoU·NMS, 남은 물건 판단 기준, 한국어 조사 처리
* `발표자료.pdf`: 발표 자료

## 실행 방식

**준비**
- `src/models/YOLO/yolo11n_int8.engine` (04 섹션 TensorRT INT8 엔진)
- `src/models/Gemma4/google_gemma-4-E2B-it-Q4_K_M.gguf`
- `whisper.cpp` (ggml-base), `.piper_venv` + `src/models/Piper/ko_KR-kss-medium.onnx`
- USB 카메라 `/dev/video0`, 마이크는 `arecord -l`로 카드 번호 확인 후 `config.py`의 `MIC_DEVICE` 수정 (기본 `plughw:0,0`)

**실행**: `src` 폴더가 있는 저장소 최상위에서
```bash
python3 Final_project/run.py
```

**사용 순서**
1. 숙소 비품만 있는 상태에서 카메라 창에서 `i` (또는 Enter 후 "체크인") → 지금 보이는 물건을 숙소 비품으로 기록
2. 짐을 풀면 2초마다 생김 · 이동 · 확인 안 됨이 터미널에 기록됨
3. 중간에 assistant 터미널에서 Enter → 5초 동안 질문 ("휴대폰 어디 있어?", "내 물건 뭐 있어?", "우산은 두고 가도 돼", "휴대폰 2는 두고 가도 돼")
4. 나가기 전 `o` (또는 "체크아웃") → 남은 물건을 음성으로 안내
   - 예: "잠깐만요! 노트북 오른쪽에 휴대폰 1이 아직 남아 있어요. 확인되지 않는 물건은 휴대폰 2예요."

**키**: 카메라 창 `i` 체크인 / `o` 체크아웃 / `c` 초기화 / `q` 종료, assistant 터미널 Enter 음성 질문 / 글자 입력 후 Enter 텍스트 질문 / `q` 종료

Jetson 없이 실행할 때는 `config.py`의 `USE_STT`, `USE_TTS`, `USE_LLM`을 `False`로 두면 키보드 입력·터미널 출력·키워드 규칙으로 동작

## 창의성 및 확장성

### 아이디어 설명
여행 중 체크아웃할 때 콘센트의 충전기, 침대 위 휴대폰, 협탁 위 여권처럼 물건을 두고 나오기 쉽고, 대부분 이미 떠난 뒤에 알게 됨. 체크리스트 앱은 직접 입력·확인해야 하고 분실물 신고는 사후 대처라서, 방에 둔 카메라가 체크인 때 상태를 기억했다가 체크아웃 때 비교해 **나가기 전에** 음성으로 알려주는 시스템을 만듦

### 구현한 내용
- **체크인 / 체크아웃 비교**: 체크인 때 보이는 물건 = 숙소 비품, 이후 생긴 물건 = 내 물건. 체크아웃 때 남은 내 물건과 안 보이는 비품을 안내
- **사진 단위 처리**: Nano 자원을 아끼려고 매 프레임이 아니라 2초마다 한 장만 YOLO 처리 (질문·명령이 오면 즉시 한 장 추가)
- **추적**: 최근 4장 중 3장에 보여야 확정, 4.5초(연속 3장) 안 보이면 "확인 안 됨". 가방에 넣은 것과 가려진 것을 카메라로는 구분할 수 없어 "챙김"으로 단정하지 않음
- **크기 비례 이동 기준**: 고정 픽셀 대신 물건 크기(대각선)의 25%로 이동 판단
- **위치 설명**: 고정 구역 없이 테두리 간격이 가장 가까운 물건 기준으로 "노트북 오른쪽", "컵 위", 없으면 "화면 왼쪽 위"
- **같은 종류 여러 개**: "휴대폰 1", "휴대폰 2"로 번호를 붙이고, "휴대폰 2는 두고 가도 돼"처럼 하나만 예외 지정 가능
- **COCO에 없는 물건**: 초록 스티커를 LAB 색 분할로 찾아 "여권"으로 처리(임의로 예시 설정), YOLO와 겹치면 클래스 무관 NMS로 하나만 남김
- **LLM은 의도만**: Gemma는 질문을 의도 JSON으로만 바꾸고, 남은 물건 판단과 답변 문장은 코드가 만듦 → 없는 물건을 지어내지 않음. 실내이므로 LLM이 음성 후보정을 해도 괜찮았음
- **프로세스 분리**: vision과 assistant를 나눠 Gemma가 답을 만드는 동안에도 카메라가 멈추지 않음. JSON은 임시 파일에 쓴 뒤 `os.replace`로 교체(06-A-7)해 쓰다 만 파일을 읽지 않음

### 확장성
- **방범**: 모든 처리가 기기 안에서 끝나 방 영상이 외부로 나가지 않으므로, 부재 중 변화 감지·사진 저장을 붙이면 CCTV처럼 사용 가능
- **탐지 대상 확장**: YOLOE(이름으로 탐지)나 직접 학습으로 이어폰·충전기·지갑 등 COCO에 없는 물건 추가
- **정확도**: Nano(Maxwell)는 INT8 가속이 없어 FP16 엔진이 더 나을 수 있음, 2초 간격이라 yolo11s도 시도 가능

## 기타 참고 사항

**한계**
- 흰 침구 위의 흰 이어폰·충전기처럼 대비가 낮은 물건은 잘 잡히지 않음 → 어두운 받침, 색 마커로 보완
- COCO에 이어폰·충전기·지갑 등이 없고, 보완할 만한 데이터셋(Lost-and-found-items)등은 옆에서 본 각도에 약함
- 같은 종류는 생김새가 아니라 위치로 추적해서, 챙긴 휴대폰 대신 다른 휴대폰을 꺼내면 같은 물건이 다시 나타난 것으로 기록됨

**작업 중 겪은 문제**
- 오탐: 마우스 오탐이 잦아 클래스는 유지하고 신뢰도 기준만 0.7로 높임. 전체 기준은 0.4에서 0.3으로 낮추고 오탐은 4장 중 3장 확정 규칙으로 거름
- COCO에 없는 모르는 물건까지 탐지하던 기능은 화면이 정신없어 제거하고 COCO + 초록 마커로만 정리
- 사라진 물건을 바로 "챙김"으로 처리하던 것을 "확인 안 됨"으로 바꾸고, 다시 보이면 복귀하도록 수정하여 혹시라도 사용자가 챙기지 않은 물건일 시 체크가능하도록 함.
