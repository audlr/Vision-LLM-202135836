# 거북목 판정기 (Turtle Neck Detector)

정면 카메라 영상 하나로 사용자의 자세를 실시간으로 관찰하고, 머리가 앞으로 빠지는 **거북목 자세**를 감지해 알려주는 프로그램입니다.
양쪽 어깨에 붙인 색 스티커(객체)와 MediaPipe로 인식한 얼굴·어깨(신체)의 **위치 관계**를 이용해 자세를 판정하고, 그 결과를 영상 위에 overlay로 표현합니다.

## 1. 프로젝트 개요

### 배경
장시간 모니터를 보며 공부하거나 일하다 보면 자신도 모르게 고개가 앞으로 나가고 목이 처집니다. 이런 자세가 반복되면 거북목(Forward Head Posture)으로 이어지지만, 정작 본인은 자세가 무너지는 순간을 알아차리기 어렵습니다.

### 목표
- 모니터 위 카메라처럼 **정면에서** 사용자를 촬영하는 환경을 가정합니다.
- 사용자가 처음에 바른 자세를 한 번 보여주면, 그 자세를 기준으로 **얼마나 무너졌는지**를 실시간으로 판정합니다.
- 나쁜 자세가 일정 시간 이상 이어지면 화면 전체로 경고해 자세를 바로잡도록 유도합니다.

### 주요 기능
| 기능 | 설명 |
|---|---|
| 어깨 마커 추적 | 양쪽 어깨의 초록 스티커를 색으로 검출하고 Kalman Filter로 추적 |
| 신체 인식 | MediaPipe Pose로 코, 눈, 어깨 위치 인식 |
| 개인 맞춤 기준 | READY 버튼을 누른 뒤 10초간의 바른 자세를 기준값으로 저장 |
| 3단계 판정 | GOOD / WARNING / TURTLE NECK |
| 경고 | 거북목 자세가 5초 이상 이어지면 화면 전체 빨간 경고 |
| 통계 | 판정 시간 중 바른 자세 비율을 하단 바로 표시 |

## 2. 사용한 기술

본 섹션에서 배운 기술이 코드의 어느 부분에 쓰였는지 정리했습니다.

| 기술 | 사용 위치 | 내용 |

| Image Enhancement | 전처리 | LAB의 L(밝기) 채널에만 CLAHE를 적용해 색은 유지하면서 어두운 영역의 대비 개선 |
| 필터링 | 마커 검출 | 7×7 가우시안 블러로 색 분할 전 노이즈 제거 |

| 객체 추적 | 마커 추적 | Kalman Filter로 어깨 마커 위치 보정, 가려지면 예측 위치 사용 |
| 신체 인식 | 판정 | MediaPipe Pose Landmarker로 코, 양쪽 눈, 양쪽 어깨 위치 인식 |
| 결과 표현 | 화면 | 판정 색으로 신체 기준선 overlay, 상태 텍스트, 경고 화면, 비율 바 |

## 3. 판정 원리

### 3.1 정면에서 거북목이 보이는 방식
거북목의 표준 측정법은 옆에서 본 **CVA(두개척추각)**, 즉 목 뒤 C7 뼈와 귀를 이은 선이 수평선과 이루는 각도입니다. 하지만 정면 카메라로는 이 각도를 직접 잴 수 없습니다.

대신 머리가 앞으로 나오면 정면 영상에서는 두 가지 변화가 함께 나타납니다.

| 변화 | 이유 | 측정값 |
|---|---|---|
| **목이 짧아 보임** | 머리가 앞으로 나오면서 아래로 처짐 | 코 ~ 양 어깨 중점의 세로 거리 |
| **얼굴이 커 보임** | 머리가 카메라 쪽으로 가까워짐 | 양쪽 눈 사이 거리 |

### 3.2 어깨 너비로 정규화
사람이 의자째 카메라에 다가가면 얼굴도 커지고 목도 길어 보이기 때문에, 위 값을 그대로 쓰면 자세가 아니라 **거리 변화**에 반응하게 됩니다.
그래서 두 값을 모두 **어깨 너비로 나눈 비율**로 사용합니다. 몸 전체가 다가오면 어깨 너비도 같은 비율로 커지므로 비율은 유지되고, 머리만 앞으로 나올 때만 비율이 변합니다.

```
목 길이 비율 = (어깨 중점 y − 코 y) / 어깨 너비
얼굴 크기 비율 = 눈 사이 거리 / 어깨 너비
```

정규화의 기준이 되는 어깨 위치가 흔들리면 모든 값이 흔들리기 때문에, 어깨는 MediaPipe 좌표 대신 **색 마커**로 직접 검출합니다.

### 3.3 개인 맞춤 기준 (캘리브레이션)
목 길이와 얼굴 크기의 비율은 체형과 카메라 위치에 따라 사람마다 다릅니다. 그래서 절대 기준값 대신 사용자 본인의 바른 자세를 기준으로 삼습니다.

1. `READY?` 버튼을 누르면 10초 동안 매 프레임 두 비율을 수집합니다.
2. 수집한 값의 **중앙값**을 기준으로 저장합니다. 평균 대신 중앙값을 쓰면 중간에 잠깐 움직인 프레임의 영향을 덜 받습니다.

### 3.4 점수와 판정
```
목 감소율 = 1 − (현재 목 길이 비율 / 기준값)
얼굴 증가율 = (현재 얼굴 크기 비율 / 기준값) − 1
점수 = 목 감소율 + 얼굴 증가율   (최근 10프레임 평균)
```

| 점수 | 판정 | 색 |
|---|---|---|
| 0.15 미만 | GOOD | 초록 |
| 0.15 이상 0.20 미만 | WARNING | 노랑 |
| 0.20 이상 | TURTLE NECK | 빨강 |

TURTLE NECK이 5초 이상 이어지면 화면 전체가 붉게 변하며 `STRAIGHTEN UP!` 경고가 표시됩니다.

## 4. 처리 파이프라인

매 프레임 아래 순서로 처리합니다.

```
카메라 프레임 (640×480)
   │
   ├─ ① 전처리: 밝기·대비 조정 → BGR→LAB → L 채널 CLAHE
   │
   ├─ ② 신체 인식: MediaPipe Pose → 코, 눈, 어깨 좌표
   │
   ├─ ③ 마커 검출 (왼쪽·오른쪽 어깨 각각)
   │     Pose 어깨 주변 영역만 잘라냄
   │     → 가우시안 블러 → LAB 색 분할 → 열림·닫힘 → 윤곽선
   │     → Pose 어깨에 가장 가까운 윤곽선의 무게중심
   │
   ├─ ④ 객체 추적: Kalman Filter
   │     검출됨 → 예측 + 보정 / 못 찾음 → 예측만
   │     15프레임 넘게 못 찾음 → Pose 어깨 좌표로 대체
   │
   ├─ ⑤ 판정: 목 길이·얼굴 크기 비율 → 기준 대비 점수 → 3단계
   │
   └─ ⑥ 결과 표현: 기준선 overlay, 상태 텍스트, 경고, 비율 바
```

### 4.1 전처리
카메라 영상의 밝기와 대비를 먼저 보정한 뒤 LAB 색공간으로 변환합니다. LAB은 밝기(L)와 색(A, B)이 분리되어 있어서, **L 채널에만 CLAHE**를 적용하면 색은 바꾸지 않고 조명 불균형만 개선할 수 있습니다.
이렇게 만든 LAB 영상은 다시 BGR로 바꿔 화면 표시와 Pose 인식에 쓰고, LAB 영상 자체는 마커 색 분할에 그대로 재사용합니다.

### 4.2 마커 검출
양쪽 어깨에 초록 스티커를 붙여 어깨 위치를 직접 검출합니다.

- **탐색 영역 제한**: MediaPipe가 찾은 어깨 위치를 중심으로, 어깨 너비의 35% 반경 안만 잘라서 처리합니다. 처리량이 줄고 배경에 있는 같은 색 물체도 자연스럽게 무시됩니다.
- **색 분할**: 수업에서 사용한 초록 LAB 범위 `[30, 60, 90] ~ [230, 115, 180]`로 이진 마스크를 만듭니다.
- **모폴로지**: 5×5 타원 커널로 열림 2회(작은 잡티 제거), 닫힘 3회(스티커 내부 구멍 메우기)를 적용합니다.
- **윤곽선 선택**: 면적이 80 이상인 윤곽선 중 Pose 어깨와 가장 가까운 것의 무게중심을 측정값으로 씁니다.

### 4.3 객체 추적 (Kalman Filter)
수업에서 배운 Kalman Filter를 그대로 사용하며, 상태는 위치와 속도입니다.

```
mu = [[x,  y ],
      [vx, vy]]

A_t = [[1, 1],      # 다음 위치 = 현재 위치 + 속도
       [0, 1]]      # 속도는 유지
C_t = [[1, 0]]      # 위치만 측정
```

- 마커가 보이면 **Prediction + Update**, 가려지면 **Prediction만** 수행해 이동하던 방향으로 위치를 예측합니다.
- 수업 코드는 (0, 0)에서 시작하지만, 여기서는 마커를 처음 찾은 위치에서 시작해 초기에 좌표가 튀지 않게 했습니다.
- 15프레임 넘게 마커를 찾지 못하면 추적을 멈추고 MediaPipe 어깨 좌표로 대체합니다.

## 5. 화면 구성

### 5.1 단계별 화면
| 단계 | 화면 |
|---|---|
| 시작 대기 | 가운데 `READY?` 버튼, 기준선은 노란색 |
| 캘리브레이션 | `Keep good posture...` 남은 시간과 진행 바 |
| 판정 | 상태(GOOD / WARNING / TURTLE NECK), 목·얼굴 변화율, 하단 바른 자세 비율 |
| 경고 | 화면 전체 붉은색 + `STRAIGHTEN UP!` |


### 5.2 overlay 요소
모든 선과 점은 현재 판정 색(노랑 / 초록 / 빨강)으로 그려집니다.

| 요소 | 의미 |
|---|---|
| 어깨 두 점과 그 사이 선 | 어깨 위치와 어깨 너비 |
| 어깨 중점에서 코까지 세로선 | 목 길이 |
| 두 눈 사이 선 | 얼굴 크기 |
| 어깨 점이 **채워진 원** | 색 마커로 검출한 위치 |
| 어깨 점이 **빈 원** | 마커를 놓쳐 MediaPipe 어깨로 대체한 위치 (`pose shoulder: L/R` 표시) |

## 6. 실행 방법

### 6.1 환경
- NVIDIA Jetson + USB 카메라 (`/dev/video0`, GStreamer v4l2src)
- Python 3, OpenCV (GStreamer 지원), NumPy, MediaPipe (Tasks API)

### 6.2 폴더 구조
```
프로젝트/
├── Project01/
│   └── Project01_202135836_정혜인.py
└── src/models/MediaPipe/
    └── pose_landmarker_full.task
```

### 6.3 실행
프로젝트 루트(`src` 폴더가 있는 위치)에서 실행합니다.
```bash
python Project01/Project01_202135836_정혜인.py
```
노트북 웹캠으로 실행하려면 `cap = cv2.VideoCapture(0)` 줄의 주석을 풀고 바로 위 GStreamer 줄을 주석 처리합니다.

### 6.4 사용 순서
1. 양쪽 어깨 끝(견봉)에 초록 스티커를 붙이고 카메라 정면에 앉습니다.
2. 화면 가운데 `READY?` 버튼을 클릭(또는 스페이스)합니다.
3. 10초 동안 바른 자세를 유지합니다.
4. 이후 자세가 실시간으로 판정됩니다.

| 키 | 동작 |
|---|---|
| 마우스 클릭 / `Space` | 캘리브레이션 시작 |
| `c` | 처음(READY 화면)으로 돌아가 기준 다시 측정 |
| `q` | 종료 |

| 분류 | 이름 | 기본값 | 설명 |
|---|---|---|---|
| 판정 | `WARN_SCORE`, `BAD_SCORE` | 0.15, 0.20 | WARNING / TURTLE NECK 기준 점수 |
| | `CALIB_SEC` | 10 | 캘리브레이션 시간(초) |
| | `ALERT_SEC` | 5 | 경고까지 거북목 지속 시간(초) |

| | `CLAHE_CLIP`, `CLAHE_TILE` | 2.0, 8 | CLAHE 대비 제한, 타일 크기 |
| | `BLUR_K`, `MORPH_K` | 7, 5 | 블러, 모폴로지 커널 크기 |
| | `OPEN_ITER`, `CLOSE_ITER` | 2, 3 | 열림 / 닫힘 반복 횟수 |
| 마커 | `LAB_LOW`, `LAB_HIGH` | [30,60,90], [230,115,180] | 초록 스티커 LAB 범위 |
| | `SEARCH_RATIO` | 0.35 | 어깨 너비 대비 탐색 반경 |
| | `MIN_AREA` | 80 | 마커로 인정할 최소 면적 |
| | `LOST_LIMIT` | 15 | Pose 어깨로 대체하기까지 허용하는 놓친 프레임 수 |
| 표시 | `LINE`, `DOT` | 3, 5 | 선 두께, 점 반지름 |
| | `TEXT`, `TEXT_L` | 0.5, 0.6 | 글자 크기 |

**튜닝**
- 판정이 너무 민감하거나 둔하면 화면의 `Neck`, `Face` 변화율을 보면서 `WARN_SCORE`, `BAD_SCORE`를 조정합니다.
- 스티커가 잡히지 않으면(어깨 점이 계속 빈 원이면) 조명에 맞게 `LAB_LOW`, `LAB_HIGH`를 조정합니다. 형광 초록처럼 아주 진한 색은 A_low를 낮추고 B_high를 높여야 합니다.

## 8. 코드 구조

처리 단계마다 함수로 나눠, `main()`에는 "프레임 읽기 → 키 처리 → 프레임 처리 → 출력"만 남겼습니다.
전역 변수 대신 상태 딕셔너리 `S` 하나에 모드, 캘리브레이션 값, 통계, 추적 상태를 모아 관리합니다.

```
main()
 └─ 매 프레임: handle_key() → process() → imshow
                              │
                              ├─ preprocess()      1. 전처리
                              ├─ detect_body()     2. 신체 인식
                              ├─ get_shoulders()   3·4. 마커 검출 + 추적
                              │    ├─ find_marker()
                              │    └─ track() → KalmanFilter()
                              ├─ measure()         5. 목 길이·얼굴 크기 측정
                              ├─ calibrate()       CALIB 상태: 기준 측정
                              ├─ evaluate()        RUN 상태: 판정 (judge)
                              ├─ draw_body() / draw_button()
                              └─ update_stats()    경고, 비율 바
```

| 1. 전처리 | `preprocess()` | 밝기·대비 조정, LAB 변환, CLAHE. 표시용 BGR과 색 분할용 LAB 반환 |
